# SauceDemo Manual Testing Project

## Project Overview
A self-practice Manual Testing project using the SauceDemo e-commerce web application.

## Modules Tested
- Login
- Shopping Cart
- Checkout
- Product Sorting
- Order Confirmation

## Testing Activities
- Manual Test Case Design and Execution
- Functional Testing
- Regression Testing
- Bug Identification and Reporting
- Test Execution Summary

## Tools Used
- SauceDemo
- Microsoft Excel
- GitHub

## Project Deliverable
Excel workbook containing test cases, bug reports, regression test cases and test summary.

## Project Type
Self-Practice Manual Testing Project
